# JUSTCREATE — product

**What it is:** a personal visual-inspiration workspace. A Chrome extension saves images, screenshots, videos, posts and pages onto one board per user, a full Excalidraw canvas; AI groups them into style clusters and writes a cited `design.md` that coding agents (Claude Code, Cursor, via MCP) build from.

**Who it's for:** web developers, indie hackers and designers who build with AI coding agents. Right now: one person, running it locally.

**Core loop:** capture → curate on the board → accept clusters → generate design.md → hand it to an agent.

**Surfaces and modes**
- The board (Excalidraw canvas + grid), clusters, design.md editor, settings, extension connect: **Operate**.
- Landing page (`/`): **Persuade**.
- Privacy, terms: **Read**.

**Product truths to keep**
- Every design.md claim cites a saved reference and is tagged Observed or Inferred.
- The user stays in control: AI suggests clusters; accept, reject, rename, merge.
- The board is private.

**Visual direction (chosen by the owner, 2026-10-29):** an Excalidraw-like hand-drawn world — handwritten type, sketchy strokes, paper background, ink only (no accent colour). Long-form text (design.md, notes, legal) stays in a clean readable face.
